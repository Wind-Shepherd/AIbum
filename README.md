# AIbum 智慧相册

本地可运行的参赛原型：多用户私人照片库、自动标签及人工修正、中文文搜图、图搜图。**不提供图文组合搜索。** 目标规模为每用户约 500 张，当前默认限制 500 张。照片只在本机处理，首次下载模型需要联网；服务运行时仅加载本地权重。

当前阶段：本地产品与验证。比赛截止日期：**2026-11-30**。华为云、CodeArts 与 Skills 实践属于下一阶段，尚未进行部署。

## 在当前电脑启动

项目已提供一键启动脚本 **`启动网站.bat`**。在项目根目录中直接双击该文件即可启动 AIbum。

启动脚本会自动：

1. 使用项目自带的 `.venv` 虚拟环境；
2. 启动 Uvicorn 服务；
3. 监听 `127.0.0.1:8000`；
4. 等待服务启动后自动打开默认浏览器并访问 http://127.0.0.1:8000 。

启动后请保持弹出的 Python/Uvicorn 运行窗口打开，关闭该窗口即停止 AIbum 服务。

如果浏览器没有自动打开，可手动访问：

```text
http://127.0.0.1:8000
```

不要重复启动多个服务实例。如果启动时出现 `WinError 10048`，说明 8000 端口已被占用。此时先访问 http://127.0.0.1:8000 检查 AIbum 是否已经运行；如果已有服务正在运行，无需再次启动。

首次注册自己的账户后务必保存页面展示的恢复码。

现有 `.venv` 与 `models/chinese-clip` 已准备好。虚拟环境不能直接复制到另一台电脑使用。
## 新环境准备

建议 Python **3.12**（64 位）、至少 8 GB 内存。初次安装需给依赖、约 750 MB 模型与转换副本预留数 GB 空间；照片另计。CPU 可运行，无需付费模型 API。实际硬件和照片规模仍需测量。

Windows：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\prepare_model.py
.\start.ps1
```

Linux/macOS（本地开发）：

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/prepare_model.py
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

模型来自官方 `OFA-Sys/chinese-clip-vit-base-patch16`。准备脚本固定到 `scripts/prepare_model.py` 中的已验证版本，将官方权重以 `weights_only=True` 加载后保存为 safetensors。下载失败后可重新执行；服务本身不会自动下载。没有模型时可上传、浏览及手动编辑，AI 分析失败会保留照片；准备模型、重启服务后在详情中点击“重新分析”。

## 使用流程

1. 注册并保存恢复码。照片、相册、标签和搜索结果按账户隔离。
2. 上传 JPG/PNG/WebP，支持多选逐张上传、进度、同用户去重。单图限 20 MiB、4000 万像素。
3. 后台完成分析后显示推荐标签。标签是有限词库的零样本建议，可以修改或清空；人工修改后，重新分析不覆盖人工标签。
4. 在搜索面板切换 **文搜图 / 图搜图**，输入描述或放入参考图，拖动“最低匹配分数”控制结果范围。参考图不保存到照片库；详情中的“找相似”会显示参考照片本身。
5. 相册、标签、收藏、地点和日期筛选可与任一种搜索一起使用。日期优先使用 EXIF 拍摄日期，缺失时回退 UTC 上传日期。地点手动填写；未实现 GPS 地理编码。
6. “我的影集”是默认入口；“全部照片”“收藏照片”“时光轴”“回收站”独立切换。时光轴拖动月份刻度筛选时期；显示大小滑杆最小档为密集缩略图。勾选照片可批量收藏、移动和移入回收站。
7. “账户安全”支持修改密码与重新生成恢复码。修改/重置密码会撤销该用户全部会话。
8. 右下角唱片可打开播放器。每个账户可上传最多 50 首 MP3、WAV、OGG 歌曲（每首不超过 15 MiB），播放、切歌和移除；歌曲只对当前账户可见。首次播放须由用户点击。

### 密码找回

登录页“忘记密码”使用 **用户名＋恢复码＋新密码**。恢复码只显示一次，服务器仅保存摘要；使用后立即失效并生成新码。恢复码不是邮件验证码。目前未接 SMTP 邮箱找回。已登录时可凭当前密码重新生成恢复码。

若密码和恢复码都丢失，界面不会允许仅凭用户名接管账户。生产环境的人工身份核验流程及邮箱找回需要后续设计。

### 管理员

不内置通用管理员密码，也不自动把第一个注册者设为管理员。由本机维护者创建专用账号：

```powershell
.\.venv\Scripts\python.exe scripts\manage.py create-admin 你的管理员用户名
```

按提示输入两次密码（输入时不显示），保存一次性恢复码。在 `/admin` 或首页“管理员入口”登录。控制台提供账户统计、照片用量、模型状态、用户搜索和启用/停用操作；停用立即撤销会话。管理员也不能访问他人照片。页面禁止停用管理员。已有账户可用 `scripts/manage.py make-admin 用户名` 授权，普通账户恢复启用可用 `scripts/manage.py activate 用户名`。

## 拾光界面与检索

前端采用暖纸色、陶土色、衬线标题与相纸卡片；包含逐张显影、悬停翻阅、拖拽反馈、弹窗展开动效，支持手机布局与系统“减少动态效果”设置，无外部字体或图片依赖。

左侧“标签”显示复选框和数量，多选匹配任一标签；其他筛选也保留在侧栏。图搜图支持拖入单张 JPG/PNG/WebP，或点击选择；显示预览，可移除重选。参考图仅用于检索，不自动存入相册。

搜索页提供连续匹配分数滑杆；用户设定的分数直接作为最低余弦门槛。未指定分数的 API 请求仍使用原有启发式过滤。分数不是识别概率，门槛仍需用真实照片和查询标注校准。

## 验证

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts\smoke_model.py --download
```

首次 `--download` 下载两张公开文档示例图到 `tmp/samples`；后续直接运行 `scripts/smoke_model.py` 即可离线复测。测试使用临时账户和数据库，不写入正式 `data/`。模型报告在 `docs/模型冒烟测试.json`。API 流程测试使用确定性替身，与真实模型结果分开记录。

两张照片上的通过结果不是完整准确率；500 条合成向量的排名耗时不是 500 张真实照片全流程或多用户并发压测。见 `docs/测试与验收.md`。

## 目录与接口

```text
app/                   后端、数据库、模型和后台任务
web/                   可替换的 HTML/CSS/JavaScript 前端
scripts/               模型准备、真实模型验证、本地管理员工具
tests/                 账户、照片、搜索和安全流程测试
docs/                  需求、规划、验证和交接记录
data/                  正式数据库与用户照片（不入 Git）
models/                模型权重（不入 Git）
tmp/                   测试素材和隔离数据（不入 Git）
```

API 结构见 http://127.0.0.1:8000/openapi.json ，交互文档为 `/docs`（文档 UI 使用外部 CDN，离线时可直接读取 OpenAPI JSON）。写请求带 `X-AIbum-Request: 1`，使用同源 Cookie 身份验证。不得将照片目录直接作为静态网站发布。

核心接口：`/api/auth/*`、`/api/photos`、`/api/photos/{id}`、`/api/photos/{id}/file`、`/api/photos/{id}/retry`、`/api/photos/{id}/similar`、`/api/search`、`/api/albums`、`/api/tags`、`/api/music/tracks`、`/api/admin/users`。`/api/search` 是 multipart 请求，只能提供 text 或 image 之一。

## 配置与维护

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| AIBUM_DATA_DIR | 项目下 data | 私有照片和 SQLite 数据目录 |
| AIBUM_MODEL_PATH | models/chinese-clip | 本地模型目录 |
| AIBUM_DEVICE | cpu | 可按 PyTorch 环境选择 cuda |
| AIBUM_ALLOWED_HOSTS | localhost,127.0.0.1,testserver | Host 白名单，多个用逗号分隔 |
| AIBUM_SECURE_COOKIE | 0 | 云部署配置 HTTPS 后设为 1 |

当前使用单进程 Uvicorn＋一个后台分析线程，**不要加 `--workers` 多进程参数**。后台任务状态持久化，重启会恢复处理中任务。SQLite 使用短连接及 WAL；用户照片不写入日志。

备份：先停止服务，再同时复制整个 `data/`。恢复时指向备份副本启动，检查账户、照片、原图和检索后再切换。不要只备份数据库而丢掉 `photos/`，也不要把测试用 `tmp/browser-data` 当作正式数据。崩溃发生在文件已落盘、数据库尚未提交的极小窗口可能留下孤立文件，当前未做自动垃圾回收；备份时保留它们，避免误删。

## 个人中心

登录后点击右上角“个人中心”。个人资料可修改昵称、上传头像；头像支持 JPG/PNG/WebP，最大 5 MiB，先预览再保存，保存时居中裁剪。昵称只用于显示，登录仍使用原用户名。账户安全栏集中提供修改密码和重新生成恢复码。

头像与昵称保存在当前数据目录的数据库，已有账户启动时自动补充字段，头像不占照片配额。更新后需重启后端服务。

## 影集、时光轴与回收站

首页默认的“我的影集”支持网盘式子文件夹、面包屑导航、返回上一级动效和照片封面。选择照片并“移动所选”可调整归类；影集管理可重命名或移动文件夹。在照片详情点击“设为影集封面”使用该文件夹内的照片。密集/缩略/相纸/大幅显示大小会保存在当前浏览器。删除文件夹不会删除照片，子文件夹移至上一层。

“时光轴”按拍摄日期归组，可切换单点或区间筛选，并选择年或月刻度；缺失拍摄日期时使用上传日期并标识。照片详情可补充日期与最多 4000 字的故事，翻到背面以中文草书展示，支持清晰阅读。点击“随机拾光”随机重访一张照片。

普通删除现在移入“回收站”，可以批量恢复或永久删除。回收站仍占 500 张配额，不自动清理。重复上传已在回收站中的照片会提示先恢复。永久删除不可撤销。

字体采用 Google Fonts 的 [Liu Jian Mao Cao](https://github.com/google/fonts/tree/main/ofl/liujianmaocao)，随项目本地分发，保留 `web/fonts/OFL.txt`；它的许可证独立于本项目 MIT 许可证。缺字使用系统楷体回退。
