命令：`.venv\Scripts\python.exe -m pytest -q`

结果：**9 组测试全部通过**，最近一次执行约 6.6 秒。

| 测试组 | 验证内容 |

| 管理员 | 权限检查、停用撤销会话和拒绝登录、启用恢复、禁止停用管理员 |

## 真实模型验证

命令：`.venv\Scripts\python.exe scripts\smoke_model.py`，首次加 `--download` 获取公开样例。

Chinese-CLIP ViT-B/16，revision `36e679e65c2a2fead755ae21162091293ad37834`，CPU。两张公开文档样例用无语义文件名上传，经过正式 API 和后台分析链路。

| 检查 | 实测结果 |
| --- | --- |
| 中文“两只猫” | 猫图第 1，分数约 0.438；该次接口内部耗时 44 ms |
| 中文“一只狗” | 狗图第 1，分数约 0.405；该次接口内部耗时 26 ms |
| 两张图分别以图搜图 | 对应原图均第 1，相似度 > 0.99 |
| 自动标签 | 猫图为“猫、室内”；狗图为“狗” |
| 冷加载并分析两张图 | 约 9.17 秒，包含模型加载及标签文本编码 |
| 500 条合成向量排名 | 20 次：p50 10.96 ms，p95 13.28 ms |

500 条测试包括数据库读取和 Top-K 组装，**不含模型推理、真实 500 张导入、多用户并发和浏览器网络耗时**。机器状态影响耗时。原始结果见 `模型冒烟测试.json`，不是 Recall/mAP 的正式数据集评估。

已修复 Transformers 文本池化接口兼容问题：按官方模型 forward 中的 CLS 投影计算，不是文件名匹配或假向量。

## 浏览器验收

使用独立 `tmp/browser-data`，实际检查：登录和照片网格；桌面 1280×900 与窄屏约 300 px；中文搜索及分数；详情、人工标签修改和收藏保存；参考图选择后文字输入停用、图搜图原图命中 1.000；多图上传进度与去重；管理员账户/容量列表。

浏览器测试修复了 id=reset 的按钮覆盖 HTMLFormElement.reset 方法、导致登录后初始化失败的问题。密码重置、停用和永久删除等状态变更由隔离 API 测试验证，未宣称全都经过浏览器点击验收。

## 尚未验证与已知边界

- 未用 500 张真实照片完成导入/质量评估；未测正式多用户并发、CUDA 或华为云。
- 标签来自固定词库，阈值为启发式而非概率；复杂场景和词库外对象可能误标/漏标。
- 批量上传逐张提交、状态每 4 秒轮询，未实现断点续传。
- 本地密码找回使用恢复码，未接邮箱或短信；管理员范围是账户查看与启停。
- SQLite 与模型按单进程运行；公网部署另行配置。
- 普通文件/数据库异常有补偿，进程恰在文件落盘与登记之间中断时可能留下孤立文件；当前不自动回收，避免误删。
- 上传日期用 UTC，EXIF 无时区时保留原时间；地点手动填写，无 GPS 地理反查。
