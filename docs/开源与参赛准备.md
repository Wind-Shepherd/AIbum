# 开源与参赛准备

依据用户提供的赛题资料，当前智慧相册方向与“基于华为云产品打造 AI 创新应用”更接近。选题最终以队伍报名与组委会规则为准。

## 可展示的产品闭环

1. 注册账户并保存恢复码，进入空相册。
2. 批量导入授权样本，展示上传进度和后台分析状态。
3. 按自动标签浏览，修正一个误标，演示用户对标签的控制。
4. 输入“草地上的狗”等中文描述，通过语义查找图片。
5. 上传参考图做图搜图，展示相似度及图库中找相似。
6. 收藏、创建相册、移动和重命名照片。
7. 切换另一账户展示数据隔离；管理员页面可看到账户用量、分析统计、反馈和处理记录，不浏览他人原图。
8. 展示一次失败重试或恢复码找回，说明系统可维护性。

## 华为云实践待办

- 团队实际下载并使用华为云码道 CodeArts 代码智能体。
- 在真实项目中用其完成可验证任务，例如前端迭代、测试生成、问题修复或部署配置；保留必要截图与提交记录。
- 依据赛题和云券范围选择并真实开通所需云服务，记录 RDS、Redis 等与应用的关联方式。
- 用官方/赛题提供的 Skills 完成实际部署，并记录资源、构建、启动、访问地址和回滚步骤。
- 核查 HTTPS、域名、Host 白名单、Secure Cookie、数据持久化、凭据管理及备份恢复。

本轮本地开发不能写成“由 CodeArts 完成”，尚未使用的 RDS/Redis/MaaS 也不能在架构图中标注为已集成。照片嵌入能力不能用普通聊天 API 替代。

## 开源交付清单

应包含原创源码、依赖版本、README、启动/部署指南、测试命令、许可证、架构说明和演示材料链接。

不要提交：`data/`、`models/`、`.venv/`、`tmp/`、`.env`、云密钥、会话 Cookie、恢复码、私人照片、带个人信息的需求原文、论文原文压缩包及全文摘取。`.gitignore` 已覆盖本地这些目录和原始材料。

`LICENSE` 只授权本项目原创代码。第三方代码、模型、示例图片和论文遵循各自许可；发布前逐项确认来源与使用范围。公开演示素材及来源位于 demo/，用户明确要求保留的协作素材位于 collaboration/；两者独立于正式 data/。

按用户的协作要求，素材导入工具提供公开的隔离开发账号和演示管理员；正式库不使用这些口令，原管理员凭据不导出。云平台的账号、密钥、短信/邮件服务等由团队配置。本轮没有创建公开仓库或上传任何文件到代码托管平台。

## 后续部署决策点

当前本地服务适合单进程启动。上云后至少保证数据库和图片目录持久化；如迁移 RDS，需要补迁移脚本与事务测试；如引入 Redis，需要真实承担任务队列或限流职责；如迁移 OBS，需要私有桶和鉴权下载，不能公开照片链接。容器化、自动部署与云架构应在拿到具体资源规格和赛题 Skills 后设计，避免提前写无法运行的部署模板。
